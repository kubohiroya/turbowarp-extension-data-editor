# TurboWarp-Plus-Editorの機能拡張セキュリティ

[TurboWarp-Plus-Editor](https://kubohiroya.github.io/turbowarp-plus-editor/) と直接開く `editor.html` は、GUI標準の一括確認を使います。起動URLのスイッチと、URLを書き換える起動スクリプトは撤去しました。`project_url`・言語・hashを追加の有効化指定なしで利用できます。

共通ライブラリはプロジェクト中の拡張をまとめて確認し、すべての選択が確定するまで拡張コードを実行しません。公開rc.34のようなバンドルでは、先頭のName・ID・Description・By・License・Unsandboxedを保持して一覧に表示します。キャンセル確認の「いいえ」は選択を保持し、「はい」は読み込みを中止してEditorの初期画面へ戻ります。保存済みの選択も次回のOKを省略しません。

選択肢は、禁止アイコンの「拒否」→盾の「サンドボックスあり」→警告の「サンドボックスなし」の順です。
`Unsandboxed: required` を宣言する拡張では、「サンドボックスあり」を無効化し、動作しない理由を表示します。
「サンドボックスなし」には「必要」と表示します。必須の宣言は製作者の自己申告で、安全性の認定ではありません。

情報取得前や保存済み設定からの選択が後から非対応と分かった場合は、その選択を解除して選び直しを案内します。
全件がサンドボックスなしを必要とする場合、メタデータの確認後にそのモードを選択し、一括操作欄を非表示にします。一括操作を表示する場合も対応する拡張だけに適用します。
実行する選択の確定はメタデータ取得が完了または失敗してから行い、拒否・キャンセルの確認は引き続き利用できます。

回帰確認は下流のTurboWarp-Plus-Editorが所有するURL生成テストと統合E2Eで行います。日英の公開入口から`project_url`を使って実際のSB3読み込みを起動し、許可前の未実行、一覧メタデータ、低い画面のOK、明示承認、再読込、キャンセルを確認します。公開後は無改変のrc.34でも確認し、build-infoと配布SB3のSHA-256・実画面をIssueへ記録します。

切り戻しはGUIの変更とTurboWarp-Plus-Editorの固定ソース設定を既知の組み合わせへ戻して再配信します。承認を自動化せず、保存済みSB3を変更しません。
